# Octane User Guide

A guide for players participating in Rocket League tournaments run with Octane.

---

## Getting Started

### Signing up for a tournament

**On Discord:**

1. Look for a signup message posted by the bot (usually in a dedicated channel).
2. React with 📝 to sign up, or remove your reaction to drop out.
3. Alternatively, use `/tournament register` and enter the tournament ID shown on the signup post.

**Viewing Tournament info:**

1. The signup message with the 📝 icon will have a link to the tournament bracket, you can go there to see the full bracket as the matches go.
2. `/bracket status [tournament_id]` can be used to check your current match/previous matches/upcoming matches.

---

## Discord Commands

### ` /tournament list`
Lists recent tournaments in the server.

### `/tournament register <tournament_id>`
Registers you for a tournament. Use the ID from the signup post.

### `/tournament unregister <tournament_id>`
Removes you from a tournament. If you’re on a team, you’re moved to unassigned.

### `/tournament status [tournament_id]`
Shows your signup status for open tournaments. With a tournament ID, shows your status for that tournament.

### `/bracket view [tournament_id]`
Shows the bracket in a channel.

### `/bracket next [tournament_id]`
Shows who you play next.

### `/bracket status [tournament_id]`
Shows your full match status: previous, current, and upcoming matches.

### `/profile`
Shows your profile and MMR if you’ve linked an Epic account.

## Web Interface

### Viewing brackets

- **Guild page** (`/s/<guild-id>`): Public view of tournaments and brackets for a server.
- **Tournament selector**: Choose which tournament to view.
- **Tabs**: Participants, Teams (for 2v2/3v3), Bracket.

### Bracket view

- **Match cards**: Show matchups, opponents, and winners.
- **Round labels**: Round numbers.
- **Timestamps**: Signup deadline and tournament start time when set.

### Winners

- **Winners page**: Lists champions from completed tournaments.

---

## Tips

- **Tournament ID**: Shown on signup posts and in `/tournament list`. Use it with `/tournament register` and `/bracket` commands.
- **Signup deadline**: Check the signup post for the deadline. Signups close after that time.
- **Tournament begins**: The start time may differ from the signup deadline; both are shown when set.
